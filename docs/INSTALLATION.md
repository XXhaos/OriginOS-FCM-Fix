# 安装与使用

1. 在 Android 11 或更新版本的设备上安装 [Shizuku](https://shizuku.rikka.app/) 并按其说明启动 shell 服务。
2. 从项目 [Releases](https://github.com/XXhaos/OriginOS-FCM-Fix/releases) 下载正式 APK 并安装。
3. 打开 Guardian，授权 Shizuku，在应用页面选择需要维护的应用，再开启保护。
4. 检查界面状态。若服务不可用，先检查 Shizuku 是否运行、授权是否有效，以及系统是否提供所需接口。

设备重启后须由用户重新启动 Shizuku；Guardian 会在依赖恢复后尝试接续已开启的设置。不同签名的 APK 不能直接覆盖安装，卸载可能删除应用数据。功能不能保证消息送达，系统后台限制也可能影响运行。

后续可在主页最下方“关于”中点击“检查更新”，有新正式版本时按提示下载并交由系统确认安装；如提示安装来源权限，允许 Guardian 后返回继续即可。网络或更新失败不会关闭现有保护。

反馈问题时，在 Shizuku 卡片点击“设置”，滑到最下方，点击“导出日志”保存 JSON。导出保留排查所需的版本和运行摘要，应用名称及包名以匿名引用表示，不会自动上传。
